# 機体に入る ssh の鍵

- `id_ed25519_turtlebot`（**秘密鍵**）と `id_ed25519_turtlebot.pub`（公開鍵）の組を、このリポジトリに入れてある。
  機体（TB-3）の `ubuntu` ユーザーは、パスワードでは入れず、この鍵だけで入れる。
- 秘密鍵を公開リポジトリに入れたのは、持ち主の判断（引き継ぎの手間を減らすため。この鍵は、この機体にしか効かない専用鍵で、パスフレーズなし）。
  **機体は、信頼できるネットワークにだけつなぐこと。** この鍵で入った人は、機体の root 相当の操作ができる。
- 使うとき: `tb3ctl init`（鍵の欄を空のまま）か `tb3ctl install-key` が、この鍵を `~/.ssh/` に置いて `config/tb3.env` に書く。手作業は要らない。
- 自分専用の鍵に替えるとき: 自分の公開鍵を足して（`tb3ctl add-key ~/.ssh/id_ed25519.pub`）、機体の
  `~/.ssh/authorized_keys` からこの鍵の行を消し、このリポジトリからも鍵を消す。
